# Projeto de Detecção de Câncer de Mama

Este projeto é um modelo de deep learning para detectar câncer de mama a partir de imagens de ultrassom.

## Referência

Referência oficial: Al-Dhabyani W, Gomaa M, Khaled H, Fahmy A. Dataset of breast ultrasound images. Data in Brief. 2020 Feb;28:104863. DOI: 10.1016/j.dib.2019.104863
